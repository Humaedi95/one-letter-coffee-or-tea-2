# One Letter: Coffee or Tea

Entry for the make.fun bounty [One Letter: Coffee or Tea](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0).

The program writes exactly one letter — `A` for coffee — to `/output/entry.txt`: 1 byte of UTF-8, no newline, no explanation, no punctuation.

## Run

```sh
bun main.ts
# or: node --experimental-strip-types main.ts
```

Then `/output/entry.txt` contains exactly `A`.
